# System Requirements

To work with TypeScript (.ts files), you need the following installed:

## 1. Node.js
Node.js is a JavaScript runtime that allows you to run JavaScript and TypeScript code outside the browser. It is required to execute and test your code locally.

### How to Install Node.js
1. Go to the official Node.js download page: [https://nodejs.org/es/download](https://nodejs.org/es/download)
2. Download the installer for your operating system (Windows, macOS, or Linux).
3. Run the installer and follow the instructions to complete the installation.

## 2. npm (Node Package Manager)
npm comes bundled with Node.js and is used to manage project dependencies. You will use npm to install TypeScript and other necessary packages for your project.

> **Note:**  
> When you install Node.js, npm is automatically installed as well. You do not need to install npm separately.

## 3. TypeScript
TypeScript is a superset of JavaScript that adds static typing. You need to install the TypeScript compiler to work with `.ts` files.

### How to Install TypeScript
Open your terminal and run the following command:
```bash
npm install -g typescript
```
verify the installation of .ts
```bash
tsc -v
```
### Use the next terminal line
Init the project with .ts,
This is the config for ts in the project
```bash
tsc --init
```
